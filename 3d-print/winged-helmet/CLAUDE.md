# Winged helmet (3D print project)

Before working on anything in this folder, read `HANDOFF.md` here in full.

- The shell, seam dowels, cheek guard L, front H badge and the wing medallions are already printed; never change anything they mate with.
- Run scripts with `source/` as the working directory. Never run `mount_build.py`, `plates_build.py`, or `conn_build.py` into `print/`.
- Hand the user full Windows paths to every project they should open in Orca (File > Open Project).
