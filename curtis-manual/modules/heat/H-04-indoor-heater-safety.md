Use a portable fuel heater indoors only if it is made for indoor use, and only with these safeguards.

## You need
- Heater labeled for indoor use (propane models with oxygen depletion sensor and tip-over shutoff)
- Correct fuel: 1-K kerosene for kerosene heaters; small propane cylinders as the label allows
- Battery CO alarm and smoke alarm
- ABC fire extinguisher

## Steps
1. Read the label. If it does not say indoor use, do not use it inside. Never use a grill, camp stove or outdoor heater indoors.
2. Put CO alarms in the room and on every level.
3. Set the heater on a hard, level floor, 3 feet from anything that can burn: bedding, curtains, people, pets.
4. Crack a window about an inch for fresh air, as the manual directs.
5. Refuel kerosene heaters outdoors, only after the heater is off and cool.
6. Store fuel outside the living space in approved, labeled containers.
7. Turn the heater off when you sleep or leave the room.

## Caution
Never use gasoline or camp fuel in a kerosene heater; it can explode. If anyone has headache, dizziness, nausea or confusion, get everyone outside and call 911. See [[Q-02]].

## Field note
Kerosene stored in a red gas can gets mixed up with gasoline. Use a blue can for kerosene (the common U.S. color code) and a yellow one for diesel, and label each in marker as well.
